# 🧠 Psychosomatic Telegram Bot

Telegram-бот по психосоматике с интеграцией YandexGPT.

---

## 📋 О проекте

Бот помогает пользователям исследовать возможную связь между физическими симптомами и психоэмоциональным состоянием. Использует YandexGPT для генерации бережных психосоматических гипотез.

**Важно:** бот не ставит медицинские диагнозы и не заменяет врача.
